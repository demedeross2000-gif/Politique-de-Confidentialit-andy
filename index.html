Politique de Confidentialité – Andy

Dernière mise à jour : 10 Mars 2026

1. Introduction

La présente Politique de Confidentialité explique comment l’application Andy collecte, utilise, protège et partage les informations des utilisateurs dans le cadre des missions vocales proposées sur la plateforme.

En utilisant l’application, vous acceptez les pratiques décrites dans cette politique.

2. Données Collectées

Nous pouvons collecter les catégories de données suivantes :

  • Informations d’identification : Nom, prénom, adresse email, numéro de téléphone.
  • Données vocales : Enregistrements audio soumis dans le cadre des missions.
  • Données démographiques : Âge, genre, langue parlée, région.
  • Données techniques : Adresse IP, type d’appareil, système d’exploitation, données de connexion et journaux d’activité.

3. Finalité de la Collecte

Les données sont collectées pour :

  • Permettre la participation aux missions vocales.
  • Analyser et structurer les enregistrements audio.
  • Améliorer la qualité des données.
  • Développer des technologies linguistiques.
  • Fournir des ensembles de données (datasets) à des partenaires technologiques.
  • Assurer la sécurité et prévenir la fraude.

4. Partage des Données

Les données vocales peuvent être partagées avec :

  • Des entreprises technologiques.
  • Des instituts de recherche.
  • Des partenaires spécialisés en intelligence artificielle.

Lorsque cela est possible, les données sont anonymisées avant partage.

Nous ne vendons pas vos informations personnelles identifiables sans base légale appropriée.

5. Conservation des Données

Les données peuvent être conservées aussi longtemps que nécessaire pour :

  • Les finalités technologiques et commerciales.
  • Le respect des obligations légales.
  • L’amélioration continue des modèles d’intelligence artificielle.

Les données déjà intégrées dans des modèles IA peuvent ne pas être techniquement supprimables.

6. Sécurité

Nous mettons en œuvre des mesures techniques et organisationnelles pour protéger les données contre :

  • L’accès non autorisé
  • La perte
  • La divulgation
  • La modification

7. Vos Droits

Vous pouvez :

  • Demander l’accès à vos données personnelles.
  • Demander la correction d’informations inexactes.
  • Demander la suppression de votre compte.
  • Retirer votre consentement pour les futures collectes.

Les données peuvent être traitées ou stockées en dehors de la Côte d’Ivoire si cela est nécessaire aux finalités technologiques décrites.
